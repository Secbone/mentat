# ACP 回放样本

`multiturn-tooling.json` 提取自2026-10-15主实验的24条任务轨迹（本地目录 `.mentat/experiments/multiturn-20261015-v2/`）。仅保留入站工具调用、工具更新和权限请求，共124帧：17次工具开始、86次更新、21次权限请求。

原生会话ID与权限请求ID已替换；工具ID增加会话命名空间以合并回放。参数及结果为合成任务产生的内容，保留了晚到参数、重复更新和嵌套错误文本形态。它们是待测数据，尤其包含被拒绝的代码和不可信记忆提案；回放程序不会执行其中代码，也不会向真实模型发请求。

`replay-acp-agent.mjs` 等待每次权限回复后继续，并将实际收到的决定作为文本回显。测试对照冻结帧检查参数、内容、文本和权限配对，而非只检查执行是否结束。
