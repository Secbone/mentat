本次证明统一宿主、执行契约、文件记忆一致性和日志查询链路能够运行，未以这次工程验证证明个人助手长期学习效果提升。

- 原15包工作树基线：134项行为测试通过，1项Docker跳过；7项架构规则通过。
- 重构后17包：171项行为测试通过，1项Docker跳过；7项架构规则通过；17包类型检查通过。
- 个人助手实验执行器：7项测试通过；全部实验脚本TypeScript检查通过。
- 新增的真实CLI子进程测试覆盖run、chat、trace查询/检查、反馈、对比、记忆演化及Git迭代命令。
- 独立Node进程并发测试：4个进程、各5次提交，20条记忆与20条审计均保留。
- 真实MCP子进程验证候选隔离、活跃规则保护、候选检索、事务ID和独立事件分片。
- 真实Git工作区验证候选提交、保护路径拒绝、回滚；新增评测异常回滚与回滚失败可见性验证。
- 外部依赖包锁定条目和snapshots与重构基线一致，没有因拆包升级第三方依赖。

## 关键故障与恢复案例

| 案例 | 验收结果 |
|---|---|
| send返回但任务尚未结束 | 等待run.settled，不提前成功 |
| send永不返回 | 到期记录失败、中断并有界关闭，拒绝复用 |
| 启动超时、会话晚到 | 调用及时失败，晚到会话释放 |
| 已取消或并发调用 | 不发送已取消输入，拒绝重叠执行 |
| 重复结束事件 | 一次最终状态 |
| 文件多实例及多进程写入 | 不覆盖旧快照、不丢条目 |
| 版本过期提交 | 写入和审计前报告冲突 |
| 数据损坏 | 拒绝覆盖，保留原文件 |
| 审计失败 | MEMORY_COMMIT_PENDING与journal保留；恢复后审计幂等 |
| 旧记忆迁移 | 整批数据和审计可恢复，旧条目标为未确认 |
| 日志观察者失败 | 诊断可见，不把已成功记忆提交伪装为未提交 |
| 进程中断/日志尾部损坏 | 已记录事件可读，报告缺口或未结束轮次 |
| 工具大输出 | 内容文件保留完整结果，读取校验哈希 |
| 日志容量超限 | 显式capture.gap和incomplete |
| 反馈追加 | 必须引用已有turn，经验摘要可读取纠正及来源 |

## 实际DeepSeek冒烟

通过本机已授权OpenCode ACP执行。三轮场景：默认中文简洁格式与周末时间约束、单轮段落格式例外、下一轮恢复默认格式。

- 初次三轮：3轮执行正常结束，160条事件，0采集缺口，0轨迹契约错误。
- 最终代码再次一轮：1轮正常结束，43条事件，0缺口，0契约错误。
- 最终运行由ACP诊断确认requested/effective均为`opencode-go/deepseek-v4.1-flash`，不是只根据命令参数推定模型。
- 模型能引用历史偏好、响应当前格式例外，并在下一轮恢复。此为单个合成交互观察，不是泛化准确率或学习增益。

观察到的业务问题：模型把“11点前到家”排到11:00，第三轮才补充建议10:35出发。按严格早于11:00解释，主时间表存在边界问题。因此不能把done或无轨迹错误当作任务验收通过。该案例保留为后续时间约束质量回归证据，本次未通过修改提示词掩盖问题。
